# Kit de lancement (sans contacter personne)

## Description GitHub (une ligne)
Lecture adaptée (dyslexie, langage simplifié, basse vision) et vue Markdown pour agents IA — avec la preuve que rien n'a été perdu. 100 % local.

**Topics** : accessibility, dyslexia, plain-language, falc, a11y, chrome-extension, llms-txt, markdown, wcag, rgaa, french

> J'ai fait l'inverse : après chaque adaptation, un test confirme que tous les nombres, dates, montants et noms sont toujours là — sinon on revient au texte d'origine.
> Extension gratuite (dyslexie, langage simplifié, basse vision), 100 % locale. Code libre. [lien]
