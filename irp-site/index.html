Le navigateur génère l'interface optimale

L'agent IA local prend l'intent, détecte le contexte (écran, accessibilité, préférences, réseau, batterie), et génère le DOM parfait pour cet utilisateur sur cette machine. Pas de React, pas de Tailwind, pas de build — l'IA fait tout.

Fonctionnalités

Pourquoi c'est révolutionnaire

Six raisons pour lesquelles IRP change tout.

📡

50x moins de bande passante

2KB d'intent JSON au lieu de 100-500KB de HTML/CSS/JS. Idéal pour les connexions lentes et le mobile data.

♿

Accessibilité native

L'IA adapte l'interface au handicap de l'utilisateur. Plus besoin d'ARIA en post-traitement. Conformité EU 2025.

🎨

Personnalisation totale

Chaque utilisateur voit une interface optimisée pour son écran, ses préférences, son contexte. Pas de compromis.

🔧

Zéro build, zéro framework

Pas de Webpack, pas de React, pas de Tailwind. Le serveur envoie du JSON, le navigateur fait tout le reste.

🔒

Privacy by design

Le modèle IA tourne localement (Chrome API, WebLLM). Les données utilisateur ne quittent jamais le navigateur.

⚡

Cache intelligent

Le rendu est caché localement par intent + contexte. Les visites suivantes sont instantanées, même hors ligne.

Démarrage

En 30 secondes

Python 3.10+ requis. Aucune dépendance, aucun npm, aucun build.

Cloner et lancer

./start.sh — démarre le serveur IRP + le client + ouvre le navigateur

Ouvrir le client

http://localhost:3000 — le navigateur détecte les modèles IA disponibles

Le modèle se charge

WebLLM télécharge Qwen2.5-0.5B (266MB, 1 fois). Les visites suivantes sont instantanées.

L'interface est générée

L'IA locale génère le HTML/CSS/JS à partir de l'intent. Adapté à votre écran et vos préférences.

Avec le SDK Python

from irp_sdk import show_product response = show_product( product_id="widget-42", name="Super Widget", price={"amount": 29.99, "currency": "EUR"}, ) # response.to_json() → JSON IRP prêt à envoyer # response.headers() → {"Content-Type": "application/irp+json"}

Avec le SDK JavaScript

import { IRPClient } from './irp-sdk/irp-sdk.js'; const client = new IRPClient({ server: 'http://localhost:8001', mount: '#app', }); await client.init(); // détecte les renderers IA await client.navigate('/'); // fetch IRP + rendu local
Extension navigateur

IRP sur n'importe quel site

L'extension Chrome/Firefox intercepte les réponses application/irp+json et les rend localement. Aucune modification du site requise.

# Charger l'extension dans Chrome chrome://extensions → Developer mode → Load unpacked → irp-extension/ # L'extension patche fetch() et XMLHttpRequest automatiquement # Popup avec: toggle on/off, sélecteur de renderer, stats temps réel
