Les modèles locaux feront le front.
IRP les rend sûrs.

Le serveur publie du sens, pas du HTML. Un petit modèle qui tourne sur l'appareil (Gemini Nano, LFM…) adapte le texte à la personne. Le code vérifie qu'aucun nombre, date, montant ou nom n'est perdu, puis affiche. L'interface dit toujours quel modèle a travaillé.

Voir un modèle local travailler Adapter une page (collez le texte)

Comment ça marche

  1. Le contenu est décrit en composants JSON (titres, listes, étapes, tableaux, faits à ne jamais perdre).
  2. Un modèle local reformule le texte (langage simplifié, dyslexie, basse vision…). Il ne produit jamais de HTML.
  3. IRP rejette toute sortie qui perd une information, et garde une version sûre.
  4. Le rendu est déterministe, accessible par construction.

Installer sur un site : une ligne


  
Un bouton « Lecture adaptée » apparaît. Rien n'est chargé avant le clic, aucun cookie, aucune donnée envoyée.


  
Limites assumées

  
Le langage simplifié (FALC) est une aide automatique, non certifiée. Les mesures du banc d'essai portent sur un corpus synthétique. Le modèle local LFM2.5 se charge en WebGPU (environ 1 Go au premier usage).
